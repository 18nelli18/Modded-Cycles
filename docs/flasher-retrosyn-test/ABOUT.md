# RETROSYN experimental test flasher

Separate page; main remains unchanged. Includes RETROSYN, all five Syntakt engines, MACRO, ACID, WAVE and TINY, with independent Sample Wizard optional. Model-TG is blocked.

Default profile: all machines without Wizard. Use the profile buttons for all machines with Wizard or RETROSYN alone; in the latter profile Sample Wizard can also be selected independently. Supply the official Cycles OS and, for the full machine set, your official Syntakt OS. No firmware is hosted or uploaded.

Hardware testing is pending. Partial machine subsets and ChordKeys are excluded from this preview. Sources, generators and emulation proofs are in the retrosyn-machine branch / PR #1. The RETROSYN core was supplied by AveyCole without a license declaration; existing engine credits and licenses are preserved.
