# 2026-10-12-test-3-pattern-saving-both-engines

Experimental B-side pattern saving. ACID, MACRO and Model-TG remain included. Use a project saved to a normal project slot, and reload it after installing this build. Use the normal Save Project command to save all visited B-side patterns. MIDI SAVED confirms the extra save; MIDI SAVE ERR means it failed even if the audio project saved. Notes, velocity, length, routing, chance/retrigger/arp locks and both MIDI LFO configurations are stored per pattern and restored when that project loads or the device restarts. MIDI LOAD ERR leaves B-side playback/editing suspended; reload a known saved project. Missing records start empty; corrupted records are refused. Save As with a changed project identity is not supported yet: reload the destination project before editing its B-side. Audio-side LFO2 saving is not included. Extra MIDI records live in a separate ModdedCycles directory and are not part of a normal Elektron project backup or project SysEx export. This storage path has passed emulation with a simulated filesystem and needs hardware testing. FUNC + SETTINGS + TRACK enters B-side; SETTINGS + PAGE opens Sequence Genie; FUNC + PAGE opens Scale Setup. Hold a trig + RECORD to copy, or + STOP to paste, with stock COPY/PASTE popups. 6-channel USB audio is optional.

Sauvegarde expérimentale des patterns B. ACID, MACRO et Model-TG conservés. Utilisez un projet enregistré dans un slot normal et rechargez-le après installation. Save Project sauvegarde les patterns B visités. MIDI SAVED confirme cette sauvegarde ; MIDI SAVE ERR indique un échec même si le projet audio est sauvegardé. Notes, vélocité, longueur, routage, locks chance/retrigger/arp et les deux configurations LFO MIDI sont conservés par pattern et restaurés au chargement du projet ou au redémarrage. MIDI LOAD ERR suspend lecture/édition B : rechargez un projet sauvegardé connu. Les fichiers absents donnent des voies vides ; les fichiers corrompus sont refusés. Save As avec nouvelle identité de projet reste non géré : rechargez la destination avant édition B. La sauvegarde du LFO2 audio reste absente. Les fichiers MIDI annexes sont dans un dossier ModdedCycles séparé, hors backup projet Elektron ou export SysEx normal. Chaîne validée en émulation avec filesystem simulé, matériel à tester. FUNC + SETTINGS + TRACK ouvre B ; SETTINGS + PAGE ouvre Sequence Genie ; FUNC + PAGE ouvre Scale Setup. TRIG + RECORD copie, TRIG + STOP colle avec popups natifs COPY/PASTE. USB6 facultatif.
