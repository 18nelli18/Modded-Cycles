# 2026-10-12-test-3-tg-save-diagnostics

Experimental pattern saving for B-side notes and A/B LFO settings. ACID, MACRO and Model-TG remain included. Use a project saved to a normal project slot, and reload it after installing this build. Use the normal Save Project command to save all visited B-side patterns. MIDI SAVED confirms the extra save; MIDI SAVE ERR means it failed even if the audio project saved. Notes, velocity, length, routing, chance/retrigger/arp locks and both MIDI LFO configurations are stored per pattern and restored when that project loads or the device restarts. MIDI LOAD ERR leaves B-side playback/editing suspended; reload a known saved project. Missing records start empty; corrupted records are refused. Save As with a changed project identity is not supported yet: reload the destination project before editing its B-side. Audio-side LFO2 settings are also stored per pattern. Audio-side LFO1 keeps its normal stock saving. Existing MBK2 MIDI records are accepted; their audio LFO2 starts disabled. Extra MIDI records live in a separate ModdedCycles directory and are not part of a normal Elektron project backup or project SysEx export. This storage path has passed emulation with a simulated filesystem and needs hardware testing. FUNC + SETTINGS + TRACK enters B-side; SETTINGS + PAGE opens Sequence Genie; FUNC + PAGE opens Scale Setup. Hold a trig + RECORD to copy, or + STOP to paste, with stock COPY/PASTE popups. 6-channel USB audio is optional. Working-state recovery is experimental: B-side sequences and added LFO settings checkpoint automatically after changes settle. Allow up to 20 seconds before switching power off. Restart restores working checkpoints; Reload Project restores the explicit Save Project copy. Save Project remains available. Do not interrupt a disk write. Both ACID and MACRO remain available. Experimental B-side live recording: hold RECORD and press PLAY. Press PLAY again while still holding RECORD to switch quantized/unquantized recording. Keyboard and pad notes record only into the selected MIDI lane. Unquantized timing uses 1/64-step resolution; held-note lengths use whole steps. New MBK4 records retain timing offsets; MBK2/MBK3 records remain readable. Earlier saving builds cannot read MBK4 records. This build reserves one additional Model-TG cache block and requires hardware verification. Save diagnostics: full-record read-back verification corrected. A failing save now reports its stage (INIT, OWNER, SYNC, PATH, ROOT, DIR, SNAP, COMMIT, CREATE, DATA, OPEN, ALLOC, WRITE, FLUSH, CLOSE or DISK). Hardware persistence is not confirmed. Includes Model-TG and the existing mod selections; standalone core is not used. LFO2 quick assign is pending.
