# Control All Beat Repeat / Beat Repeat collectif

EN: Experimental; main is unchanged. Start a test pattern with all six tracks. Hold TRACK + RETRIG, then hold TRIG 3 (1/32), 5 (1/16), 7 (1/8) or 10 (1/4). Release RETRIG first, then try releasing TRACK first: both must return immediately through a short fade to normal playback. No latch. Try both modifier orders, changing rates, stopping transport and another project. Confirm Control All track selection and ordinary trigs stay intact. With Wizard, check a stereo sample. Report clicks, timing, unexpected screens and heavy-load audio glitches. This repeats track audio; it does not repeat outgoing MIDI notes.

FR : Experimental ; principal inchange. Lancez un pattern de test avec six pistes. Maintenez TRACK + RETRIG puis TRIG 3 (1/32), 5 (1/16), 7 (1/8) ou 10 (1/4). Relachez RETRIG puis essayez TRACK d'abord : retour normal par un court fondu dans les deux cas. Aucun latch. Testez les deux ordres, changements de division, Stop et un autre projet. Verifiez le masque Control All et les TRIG normaux. Avec Wizard, testez un sample stereo. Rapportez clics, timing, ecrans inattendus et glitches en forte charge. Audio repete ; notes MIDI sortantes non repetees.
