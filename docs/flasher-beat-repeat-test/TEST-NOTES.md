EN: Experimental; main is unchanged. Start a test pattern with all six tracks. In Control All Config, exclude some tracks first: only included tracks should repeat, excluded tracks should keep playing normally. The config choices must disappear while TRACK + RETRIG is held and return on release. Hold TRACK + RETRIG, then hold TRIG 3 (1/32), 5 (1/16), 7 (1/8) or 10 (1/4). Release RETRIG first, then try releasing TRACK first: both must return immediately through a short fade to normal playback. No latch. Try both modifier orders, changing rates, stopping transport and another project. Confirm Control All track selection and ordinary trigs stay intact. With Wizard, check a stereo sample. Report clicks, timing, unexpected screens and heavy-load audio glitches. This repeats track audio; it does not repeat outgoing MIDI notes.
