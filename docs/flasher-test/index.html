Experimental BTH test withdrawn

The experimental OUT / THRU / BTH firmware from this page caused the MIDI settings menu to freeze on a Model:Cycles. Do not build or flash firmware from the experimental test page.

If you are recovering the instrument, use the official Elektron OS. For the known-working combined MIDI behavior, use the production flasher and select the tested “MIDI OUT while in THRU” option.

Test expérimental BTH retiré

Le firmware expérimental OUT / THRU / BTH de cette page a figé le menu MIDI d'un Model:Cycles. Ne construisez ni ne flashez de firmware depuis cette page.

Pour récupérer l'instrument, utilisez l'OS officiel Elektron. Pour le comportement combiné MIDI déjà testé, utilisez le flasher de production et sélectionnez « MIDI OUT pendant THRU ».
