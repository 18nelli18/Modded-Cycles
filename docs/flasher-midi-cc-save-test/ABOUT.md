# 2026-10-13-midi-cc-save-compressed

CC saving test: Save Project now stores B-side gray-knob CC assignments and base values, plus per-step CC number/value locks with their MIDI patterns. Save, reload, then power-cycle and reload the project to verify them on hardware. Existing and new project slots are supported. Older projects without CC records start with unassigned knobs and empty CC locks. MIDI note/timing/live recording and LFO saving remain included. CC records use separate verified alternating copies; a CC error is reported separately and does not close B-side or invalidate the saved MIDI notes. All selectable mods, including ACID, MACRO and Model-TG, are retained through compatible compression. CC slides and all earlier B-side controls remain included. Hold SETTINGS and turn a gray knob to assign CC0–127/OFF; release SETTINGS and turn to send its value. Hold a TRIG and turn an assigned knob to lock it. FUNC + TRIG creates a trigless step. SETTINGS + TRIG toggles Slide on/off. SETTINGS + TRACK scrambles assigned CCs. LFO destinations use DATA to edit/confirm, BACK to cancel, and browse OFF then CC0–127 in a five-character scrolling window. CC persistence is verified in emulation and awaits hardware testing. Explicit Save Project is required; no automatic CC checkpointing yet.
