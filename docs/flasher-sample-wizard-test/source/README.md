# Sample Wizard

Experimental standalone extraction. MIT source provenance: TinyGregAudio/Model-TG 70b39dd6787770ebefc7a2d78dea1678ec012679; Slice varispeed roterodamus/Model-TG 0c567d8c9e3d0c61837e1d91ac2f5c747ea9763f.

The assembler currently retains unused TG routines, but the explicit hook manifest installs only sampler functions; it does not install global FX, stock-machine DSP replacements, mutes, Scale Lock or slides. Source is included for review; build scripts refer to development tool paths. No Elektron firmware or user samples are supplied.
