New feature shortcut guide

A.V.’s Supermodel Edition · 16 October 2026

Added gestures only; stock-style transport, copy, clear and paste actions are omitted.

Install the relevant feature first. Hold the first button while pressing or turning the next control. TRIG means a step key; pad means a track pad; DATA means LEVEL/DATA. MACHINES is the physical button sometimes called PRESET in sampler instructions.

Saved MIDI loads only when entering B-side while playback is stopped. Stop before Save Project and wait for MIDI SAVED. Sidecar MIDI files are outside Elektron SysEx backups.

Separate MIDI performance test

These two additions are experimental and available only on the MIDI performance test page, currently using the fixed six-voice 909 profile and four local WAVs.

FeatureGestureResult
MIDI beat repeatHold TRACK + RETRIG, then hold a division TRIGRetrigger each included B lane’s latest sequenced note, using its current MIDI channel and port. Release stops the repeated notes. This repeats notes rather than capturing a MIDI phrase; native A-side MIDI output is outside this test.
B-side Control All filter: audio + MIDIIn B-side, hold TRACK + MACHINES and turn SWEEP / CONTOURUpdate included internal audio filters and send CC74 / CC71 to the configured B instruments. MIDI-muted lanes receive no CC; their internal audio filters still change.
