Supermodel 2.38

Features and shortcut guideGuide des fonctions et raccourcis

Main 2.38. Hold the first button while pressing the next button or turning the named knob. TRIG means a step key; pad means a track key; DATA means LEVEL/DATA. All listed features are included.

Included features

Machines and sound
Six stock engines plus Sample Wizard, SD Vintage, Clap Vintage, SY Toy, SY Bits, Swarm LITE, MACRO, ACID, WAVE, Feral by Glycinate, Elder, TINY, Shadow, SPEAK, LEGACY, RETROSYN and MIDI Out. Elder is an original synth inspired by Junior by Fors. Machine browsing retains synth values; Wizard’s four dials stay separate while MACHINES stays open.
Performance and sequencing
Arpeggiator, held-note octave 0, ChordKeys and harmony locks, Sequence Genie, SCRAMBLE, slides, trig preview, Step Recorder, latching mute and solo.
Filters and effects
Polivoks-style track/Wizard filters, second LFO, MACRO Fine/Lo-Fi; GATED, HALL, Ring Mod, ROOM, PS1, Vinyl, Reverb and Chorus 1/2; Phaser, DUCK, DUB, Ping Pong, Delay and Crush 1/2. Opaque FX menus apply on TRACK release. Cumulative PS1/filter optimizations. Both Shimmers and all combined modes are removed.
Routing and workflow
MIDI Out with nine CC knobs, locks and two MIDI LFOs; MIDI OUT/THRU toggle; USB stereo or six tracks; permanent quick save, saved Mod Setup and optional DX diagnostics.

Effects

FeatureControlsBehavior
Reverb-slot menuHold TRACK + REVERB SIZETop to bottom: GATED, HALL, ROOM, PS1, REVERB, VINYL, CHORUS 1, CHORUS 2, RING MOD. Turn left to move up, right to move down. Browse without changing sound; release TRACK to apply, BACK to cancel.
Delay-slot menuHold TRACK + DELAY TIMETop to bottom: PHASER, DUCK, DUB, PING PONG, DELAY, CRUSH 1, CRUSH 2. From DELAY, left/up selects Ping Pong; right/down selects Crush 1 then Crush 2. Release TRACK to apply; BACK cancels.
Standard ReverbREVERB SEND / SIZE / FUNC + SIZEPer-track Send / native Size, including INF at maximum / Tone -64 through 0 to +63. Stock formatting returns immediately after leaving Chorus, even during playback.
GATED reverbREVERB SEND / SIZE; FUNC + SIZE; SETTINGS + SIZEGated Send / Gate Time; Pre-delay; Tone. Gate Time 0-127: about 40 ms-6.7 s after input falls quiet. Pre-delay 0-568 ms, 1 ms steps through 64 then 8 ms. No added echoes; dry hit stays immediate and the gate follows the delayed sound. Try Gate Time 16-32, Pre-delay 25-40 ms on a snare. Gate Time and Pre-delay belong to each pattern; save the project to preserve them after reloading.
HALL reverbREVERB SEND / SIZE / FUNC + SIZE or SETTINGS + SIZEHall Send per track / Decay / Tone. Wide stereo tail with longer reflections than ROOM. Four damped paths and two diffusers per channel at 12 kHz reuse existing reverb memory.
Ring ModREVERB SEND / SIZE / FUNC + SIZE or SETTINGS + SIZERing Send per track / Frequency / Depth. Metallic sine ring modulation replaces the reverb return. Select RING MOD below Chorus 1/2. Frequency and Depth shared by tracks in this pattern; use the native track Send for locks.
PhaserDELAY SEND / TIME / FUNC + TIME; FUNC first, then TRACK + TIMEPhaser Send per track / Rate / Depth; FUNC then TRACK + TIME is Feedback (also SETTINGS + TIME). Two-stage stereo phaser replaces the delay return. Select PHASER above DUCK. Hold FUNC before TRACK to avoid the mute latch.
DUCK delayDELAY SEND / TIME / FUNC + TIME or SETTINGS + TIME; FUNC then TRACK + TIME or DELAY SENDNative Delay Send / Time / Feedback. Hold FUNC first, then TRACK: TIME adjusts Amount; DELAY SEND adjusts Release. Strong wet ducking while the send input plays, then a swelling return; feedback remains intact. Try Amount 127, Release 32-64 on sparse notes. Amount 0 is standard Delay.
ROOM reverbREVERB SEND / SIZE / FUNC + SIZE or SETTINGS + SIZERoom Send per track / Decay / Tone. Compact stereo room tail at 12 kHz. Select ROOM above PS1; release TRACK to apply. Wet return raised by 6 dB at normal levels, with a gentle peak knee; dry level is unchanged.
PS1 reverbREVERB SEND / SIZE / FUNC + SIZE or SETTINGS + SIZEPS1 Send per track / Decay / Tone. PlayStation-inspired stereo tail, darker and grainier; cumulative processing optimizations retained. Wet return raised by 6 dB at normal levels, with a gentle peak knee; dry level is unchanged.
Chorus 1 / 2REVERB SEND / SIZE / FUNC + SIZEChorus Send per track / Speed / Depth. Speed and Depth 0-127. Replaces reverb in this slot.
VinylREVERB SEND; SIZE / FUNC + SIZE / FUNC first, then TRACK + SIZEVinyl Send; Crackle / Warble Amount / Warble Speed. Hold FUNC first, then TRACK for Speed. Send 0 is dry; Crackle 0 switches dust off. Bright independent pops/clicks continue through gaps. Track level, pan and mute apply.
Standard DelayDELAY SEND / TIME / FUNC + TIMEPer-track Delay Send / native Time / native Feedback.
DUB delayDELAY SEND / TIME / FUNC + TIME or SETTINGS + TIMEPer-track Delay Send / native Time / Feedback. Strongly filtered echoes alternate left and right, progressively narrowing in the feedback loop. Reuses the native delay and stereo bounce routing. Headphones or both outputs reveal the movement.
Ping PongDELAY SEND / TIME / FUNC + TIME or SETTINGS + TIMEPer-track send / Time / Feedback. Stereo echoes alternate left and right; listen through headphones or both outputs.
Crusher Rate / BitsCRUSH 1 or 2: TIME / FUNC + TIMERate 0-127, about 750 Hz-48 kHz / Bits 2-16. Lower Rate or Bits is rougher. CRUSH 1 keeps the direct signal clean; CRUSH 2 blends direct clean/crushed. DELAY SEND is labeled Crush Send; no delay echoes in Crush modes.
Effect settings and saveSave ProjectFX types and added controls belong to each pattern; save the project to preserve them after reloading. Blank patterns use standard Delay/Reverb and default added controls. Added FX controls have no p-lock/LFO destinations; native track sends retain their locks. Both Shimmers and all combined modes are removed.

SPEAK voice machine

FeatureControlsBehavior
Select SPEAKMACHINES: after Shadow, before LEGACYOriginal 128-word formant speech engine. Microphone; CLASS VOICE / STYLE TALK / STR 1, DEX 5, MAG 5. v90 balances phoneme levels, smooths transitions and brightens voiced harmonics while keeping hiss reduced. Start around Vol+Dist 60, Punch off.
Voice / Word / Speed / ArticulationCOLOR / SHAPE / SWEEP / CONTOURVoice/formant character / Word 0-127 / Speed (64 normal, lower slower) / Articulation. SHAPE popup shows the word and index. Word changes latch at the next trig; the other three controls remain live. Slow words now continue through quiet phoneme gaps; the idle detector no longer suspends unfinished speech.
Pitch and envelopePITCH / notes; DECAY, Fine, Punch, Gate, AttackPitch changes independently of word speed. Begin with Decay 127 to hear complete words. Existing filters and FX sends apply. Each track has its own speech state.

Mod Setup

Hold SETTINGS + TRACK until Mod Setup opens, then release both buttons. A short tap runs SCRAMBLE on release. DATA selects a row; click to edit, turn, click again to return. Stk = Stock; SIL = Silent; LTC = Latch.

FeatureControlsBehavior
PadStk / SIL Default: StkStk keeps the original track-pad behavior: a pad selects and plays its track. Silent selects the track without sounding it; hold TRACK and press a track pad to select and play. ChordKeys tracks still require TRACK + track pad to leave the track.
USB2ch / 6ch Default: 2ch2ch sends the stereo mix to the computer. 6ch sends six separate mono tracks, before pan and without the mix delay/crusher/reverb/chorus returns. Stereo audio from the computer to Cycles works in both modes. Stop playback before changing this toggle. Changing modes reconnects the USB audio device; select its new channel layout in your DAW if needed.
NumOff / On Default: OffOff keeps the original volume and pan display. On shows numeric volume and pan values when you adjust those controls.
MuteStk / LTC Default: StkStk keeps the original momentary mute controls. With LTC selected, hold TRACK and tap FUNC to stay in mute mode, then tap track pads to mute or unmute. Tap FUNC again to leave. In latched mute mode, hold FUNC and press a track pad to solo it; press the soloed pad again, or leave mute mode, to restore the previous mutes.
DelayStk / Div Default: StkStk preserves the original Delay Time display and timing. Div displays musical divisions, including dotted and triplet values, and corrects the matching timing positions to exact divisions of the tempo. Other Delay Time positions retain their original timing; this does not quantize every knob position. Applies while using Delay mode.
DXOff / On Default: OffWith DX On: tap FUNC, press FUNC again within 350 ms, hold at least 0.5 seconds, then release. Other controls cancel the gesture. Shows/resets A/P/O/N: average/peak CPU load, overruns, governor voice drops. Replaces the old shortcut; retrig latching never triggers it. Off by default.
SCRMDATA opens; turn and press DATA; BACK returnsSix checkboxes per track: Pitch, Decay, Color, Shape, Sweep, Contour. Pitch/Decay default Off; the original four default On. Choices persist across projects and power cycles; saving waits until playback stops. Wizard allows Pitch/Decay; its sample/mode controls stay excluded.

These are global preferences. BACK closes Mod Setup and saves its global preferences; each track's Scramble checklist saves when you return from its submenu. If playback is running, the save waits until it stops. Stop playback and allow saving to finish before powering off. Saved choices return after reboot. FX types and added settings are separate: each pattern remembers them, and Save Project preserves them after reloading.

Effets

FonctionCommandesComportement
Menu reverbMaintenir TRACK + REVERB SIZEDe haut en bas : GATED, HALL, ROOM, PS1, REVERB, VINYL, CHORUS 1, CHORUS 2, RING MOD. Gauche monte, droite descend. Son inchange pendant le parcours ; relacher TRACK applique, BACK annule.
Menu delayMaintenir TRACK + DELAY TIMEDe haut en bas : PHASER, DUCK, DUB, PING PONG, DELAY, CRUSH 1, CRUSH 2. Depuis DELAY, gauche/haut vers Ping Pong ; droite/bas vers Crush 1 puis Crush 2. Relacher TRACK applique ; BACK annule.
Reverb standardREVERB SEND / SIZE / FUNC + SIZESend par piste / Size natif, INF au maximum / Tone -64 a 0 a +63. Format natif restaure immediatement apres Chorus, meme en lecture.
Reverb GATEDREVERB SEND / SIZE ; FUNC + SIZE ; SETTINGS + SIZEGated Send / Gate Time ; Pre-delay ; Tone. Gate Time 0-127 : environ 40 ms-6,7 s apres le signal. Pre-delay 0-568 ms : pas de 1 ms jusqu a 64 puis 8 ms. Sans echos ajoutes ; dry immediat, gate apres le signal retarde. Essayer Gate Time 16-32 et Pre-delay 25-40 ms sur caisse claire. Gate Time et Pre-delay sont propres à chaque pattern ; sauvegardez le projet pour les conserver.
Reverb HALLREVERB SEND / SIZE / FUNC + SIZE ou SETTINGS + SIZEHall Send par piste / Decay / Tone. Queue stereo large, reflexions plus longues que ROOM. Quatre voies amorties et deux diffuseurs par canal a 12 kHz, memoire reverb reutilisee.
Ring ModREVERB SEND / SIZE / FUNC + SIZE ou SETTINGS + SIZERing Send par piste / Frequency / Depth. Modulation en anneau sinusoidale metallique dans le slot reverb. RING MOD sous Chorus 1/2. Frequency et Depth partagés par les pistes du pattern ; locks via le Send natif.
PhaserDELAY SEND / TIME / FUNC + TIME ; FUNC puis TRACK + TIMEPhaser Send par piste / Rate / Depth ; FUNC puis TRACK + TIME : Feedback (aussi SETTINGS + TIME). Phaser stereo deux etages dans le slot delay. PHASER au-dessus de DUCK. Tenir FUNC avant TRACK pour eviter le mute verrouille.
Delay DUCKDELAY SEND / TIME / FUNC + TIME ou SETTINGS + TIME ; FUNC puis TRACK + TIME ou DELAY SENDDelay Send natif / Time / Feedback. Tenir FUNC avant TRACK : TIME regle Amount ; DELAY SEND regle Release. Retour attenue pendant le signal puis remontee progressive ; feedback conserve. Essayer Amount 127, Release 32-64 sur notes espacees. Amount 0 : Delay standard.
Reverb ROOMREVERB SEND / SIZE / FUNC + SIZE ou SETTINGS + SIZERoom Send par piste / Decay / Tone. Petite ambiance stereo a 12 kHz. ROOM au-dessus de PS1 ; relacher TRACK pour appliquer. Retour wet releve de 6 dB aux niveaux usuels, avec compression douce des cretes ; dry inchange.
Reverb PS1REVERB SEND / SIZE / FUNC + SIZE ou SETTINGS + SIZEPS1 Send par piste / Decay / Tone. Queue stereo inspiree PlayStation, sombre et granuleuse ; optimisations de traitement conservees. Retour wet releve de 6 dB aux niveaux usuels, avec compression douce des cretes ; dry inchange.
Chorus 1 / 2REVERB SEND / SIZE / FUNC + SIZEChorus Send par piste / Speed / Depth. Speed et Depth 0-127. Remplace la reverb du slot.
VinylREVERB SEND ; SIZE / FUNC + SIZE / FUNC puis TRACK + SIZEVinyl Send ; Crackle / Warble Amount / Warble Speed. Tenir FUNC puis TRACK pour Speed. Send 0 sec ; Crackle 0 coupe la poussiere. Pops/clics independants dans les pauses. Volume, pan et mute respectes.
Delay standardDELAY SEND / TIME / FUNC + TIMEDelay Send par piste / Time natif / Feedback natif.
Delay DUBDELAY SEND / TIME / FUNC + TIME ou SETTINGS + TIMEDelay Send par piste / Time natif / Feedback. Echos fortement filtres alternant gauche/droite, de plus en plus etroits dans la boucle. Reutilise le delay natif et le rebond stereo. Casque ou deux sorties pour le mouvement.
Ping PongDELAY SEND / TIME / FUNC + TIME ou SETTINGS + TIMESend par piste / Time / Feedback. Echos stereo alternes gauche/droite ; casque ou deux sorties.
Crusher Rate / BitsCRUSH 1 ou 2 : TIME / FUNC + TIMERate 0-127, environ 750 Hz-48 kHz / Bits 2-16. Valeurs basses plus rugueuses. CRUSH 1 garde le direct propre ; CRUSH 2 melange direct propre/crushed. DELAY SEND affiche Crush Send ; pas d echo dans ces modes.
Reglages et sauvegarde FXSauvegarder le projetTypes FX et réglages ajoutés propres à chaque pattern ; sauvegardez le projet pour les retrouver au chargement. Les patterns vierges utilisent Delay/Reverb standard et les réglages ajoutés par défaut. Pas de destination p-lock/LFO pour les réglages ajoutés ; les envois natifs gardent leurs verrous. Shimmers et modes combinés retirés.
