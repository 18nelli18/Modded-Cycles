Supermodel 2.48

Features and shortcut guideGuide des fonctions et raccourcis

Main 2.48. Hold the first button while pressing the next button or turning the named knob. TRIG means a step key; pad means a track key; DATA means LEVEL/DATA. All listed features are included.

Included features

Machines and sound
Six stock engines plus Sample Wizard, SD Vintage, Clap Vintage, SY Toy, SY Bits, Swarm LITE, MACRO, ACID, WAVE, Feral by Glycinate, Elder, TINY, Shadow, SPEAK, LEGACY, RETROSYN, PUNCH and MIDI Out. Elder is an original synth inspired by Junior by Fors. PUNCH is an FM percussion engine by100demons (MIT).
Performance and sequencing
Arpeggiator, held-note octave 0, ChordKeys and harmony locks, Sequence Genie, SCRAMBLE, slides, trig preview, Step Recorder, latching and quantized mute and solo. Trigger-based Sidechain and per-pattern Scramble checklists.
Filters and effects
Per-track resonant filter and attack. GATED, HALL, ROOM, PS1, Vinyl, Ring Mod and two Choruses; DUCK, DUB, Ping Pong, Phaser and two Crushers.
Routing and workflow
MIDI Out with nine CC knobs, locks and two MIDI LFOs; MIDI OUT/THRU toggle; USB stereo or six tracks; permanent quick save, saved Mod Setup and optional DX diagnostics.

Effects

FeatureControlsBehavior
Reverb-slot menuHold TRACK + REVERB SIZETop to bottom: GATED, HALL, ROOM, PS1, REVERB, VINYL, CHORUS 1, CHORUS 2, RING MOD. Turn left to move up, right to move down. Browse without changing sound; release TRACK to apply, BACK to cancel.
Delay-slot menuHold TRACK + DELAY TIMETop to bottom: PHASER, DUCK, DUB, PING PONG, DELAY, CRUSH 1, CRUSH 2. From DELAY, left/up selects Ping Pong; right/down selects Crush 1 then Crush 2. Release TRACK to apply; BACK cancels.
Standard ReverbREVERB SEND / SIZE / FUNC + SIZEPer-track Send / Size, including INF at maximum / Tone -64 through 0 to +63.
GATED reverbREVERB SEND / SIZE; FUNC + SIZE; SETTINGS + SIZEGated Send / Gate Time; Pre-delay; Tone. Gate Time: about 40 ms–6.7 s after input falls quiet. Pre-delay: 0–568 ms. Try Gate Time 16–32 and Pre-delay 25–40 ms on a snare.
HALL reverbREVERB SEND / SIZE / FUNC + SIZE or SETTINGS + SIZEHall Send per track / Decay / Tone. Wide stereo tail with longer reflections than ROOM; maximum SIZE gives a long damped tail.
Ring ModREVERB SEND / SIZE / FUNC + SIZE or SETTINGS + SIZERing Send per track / Frequency / Depth. Metallic sine ring modulation replaces the reverb return. Select RING MOD below Chorus 1/2. Frequency and Depth shared by tracks in this pattern; use the native track Send for locks.
PhaserDELAY SEND / TIME / FUNC + TIME; FUNC first, then TRACK + TIMEPhaser Send per track / Rate / Depth; FUNC then TRACK + TIME is Feedback (also SETTINGS + TIME). Two-stage stereo phaser replaces the delay return. Select PHASER above DUCK. Hold FUNC before TRACK to avoid the mute latch.
DUCK delayDELAY SEND / TIME / FUNC + TIME or SETTINGS + TIME; FUNC then TRACK + TIME or DELAY SENDNative Delay Send / Time / Feedback. Hold FUNC first, then TRACK: TIME adjusts Amount; DELAY SEND adjusts Release. Strong wet ducking while the send input plays, then a swelling return; feedback remains intact. Try Amount 127, Release 32-64 on sparse notes. Amount 0 is standard Delay.
ROOM reverbREVERB SEND / SIZE / FUNC + SIZE or SETTINGS + SIZERoom Send per track / Decay / Tone. Compact stereo room ambience. Select ROOM above PS1; release TRACK to apply.
PS1 reverbREVERB SEND / SIZE / FUNC + SIZE or SETTINGS + SIZEPS1 Send per track / Decay / Tone. PlayStation-inspired stereo tail with a dark, grainy character.
Chorus 1 / 2REVERB SEND / SIZE / FUNC + SIZEChorus Send per track / Speed / Depth. Speed and Depth 0-127. Replaces reverb in this slot.
VinylREVERB SEND; SIZE / FUNC + SIZE / FUNC first, then TRACK + SIZEVinyl Send; Crackle / Warble Amount / Warble Speed. Hold FUNC first, then TRACK for Speed. Send 0 is dry; Crackle 0 switches dust off. Bright independent pops/clicks continue through gaps. Track level, pan and mute apply.
Standard DelayDELAY SEND / TIME / FUNC + TIMEPer-track Delay Send / native Time / native Feedback.
DUB delayDELAY SEND / TIME / FUNC + TIME or SETTINGS + TIMEPer-track Delay Send / native Time / Feedback. Strongly filtered stereo echoes, progressively narrowing in the feedback loop. Centered input plays on both channels from the first echo, even with zero feedback.
Ping PongDELAY SEND / TIME / FUNC + TIME or SETTINGS + TIMEPer-track send / Time / Feedback. Stereo echoes alternate left and right; listen through headphones or both outputs.
Crusher Rate / BitsCRUSH 1 or 2: TIME / FUNC + TIMERate 0-127, about 750 Hz-48 kHz / Bits 2-16. Lower Rate or Bits is rougher. CRUSH 1 keeps the direct signal clean; CRUSH 2 blends direct clean/crushed. DELAY SEND is labeled Crush Send; no delay echoes in Crush modes.
Effect settings and saveSave ProjectEach pattern remembers its selected FX types, added controls and extra sends. Save the project to keep them after reloading. Blank patterns use standard Delay/Reverb and default added controls. A queued pattern applies its FX when it begins playing. Added FX controls have no p-lock/LFO destinations; native track sends support locks.

FeatureControlsBehavior
LEGACY / selectionMACHINES: before RETROSYN and MIDI OutDexed MSFA six-operator FM with all 32 algorithms; one voice per track. MIDI Out remains last. COLOR = Velocity, SHAPE = Voice, SWEEP = Brightness, CONTOUR = EG Time. Native locks/CC/LFO mappings; Voice and Velocity are captured on the next trigger.
Voice librarySHAPE: slots 0-3132 bundled voices selected with SHAPE. The complete indexed factory voice library follows. Import a cartridge to replace the active bank.
Velocity / brightnessCOLOR / SWEEPVelocity 0-127 controls the cartridge operators response at each trigger; default 100. Brightness 64 preserves the patch. Lower softens modulation; higher adds bite.
Envelope timeCONTOUR / DECAYEG Time 64 preserves the patch envelope timing; lower is faster, higher slower. DECAY and gate still set the native amplitude envelope. PITCH and FINETUNE transpose the voice; fixed-frequency operators follow their cartridge settings.
Import a DX7 bankFlasher > WAV / DX7 bank importersStop playback. Choose a Yamaha 32-voice .syx bank, connect Model:Cycles USB MIDI, choose slot 1-16 and send. Wait for LEGACY BANK SAVED. Reusing a slot replaces it. Importing does not change the active sound.
Load a stored bankLEGACY: FUNC + MACHINES; DATA; BACKHold FUNC while pressing MACHINES to open the bank library. Turn DATA to choose; press DATA to load; BACK cancels. Factory restores the included voices. One active 32-voice bank is shared by every LEGACY track. Banks persist after reboot and are separate from Elektron project backups.

Mod Setup

Tap SETTINGS + TRACK and release to open Mod Setup. Hold the combo to run SCRAMBLE once instead; continuing to hold does not repeat it. With a TRIG held, a quick tap toggles its Scramble mark. Choose Global or Track first. DATA selects a row; click to edit, turn, click again to return. Stk = Stock; SIL = Silent; LTC = Latch.

FeatureControlsBehavior
Global / TrackDATA enters; BACK returnsGlobal: Pad, USB, Num, Mute, Dly, DX, QntM, Grv. Track: SCRM, S.Chn, Human. BACK leaves editing before returning a level. Reopening starts at the root.
Access and sound editingTap SETTINGS + TRACKAvailable from the main screen or machine selection. DATA navigates Mod Setup; sound knobs show the edited parameter for two seconds, then return to the same menu position. BACK closes the popup first, then Mod Setup; machine selection stays open underneath.
PadStk / SIL Default: StkStk keeps the original track-pad behavior: a pad selects and plays its track. Silent selects the track without sounding it; hold TRACK and press a track pad to select and play. ChordKeys tracks still require TRACK + track pad to leave the track.
USB2ch / 6ch Default: 2ch2ch sends the stereo mix to the computer. 6ch sends six separate mono tracks, before pan and without the mix delay/crusher/reverb/chorus returns. Stereo audio from the computer to Cycles works in both modes. Stop playback before changing this toggle. Changing modes reconnects the USB audio device; select its new channel layout in your DAW if needed.
NumOff / On Default: OffOff keeps the original volume and pan display. On shows numeric volume and pan values when you adjust those controls.
MuteStk / LTC Default: StkStk keeps the original momentary mute controls. With LTC selected, hold TRACK and tap FUNC to stay in mute mode, then tap track pads to mute or unmute. Tap FUNC again to leave. In latched mute mode, hold FUNC and press a track pad to solo it; press the soloed pad again, or leave mute mode, to restore the previous mutes.
Quantized mute/soloTap SETTINGS + TRACK; QntMTurn it On or Off and select the time division your mutes and solos are quantized to. Off by default.
DelayStk / Div Default: StkStk preserves the original Delay Time display and timing. Div displays musical divisions, including dotted and triplet values, and corrects the matching timing positions to exact divisions of the tempo. Other Delay Time positions retain their original timing; this does not quantize every knob position. Applies while using Delay mode.
DXOff / On Default: OffWith DX On: tap FUNC, press FUNC again within 350 ms, hold at least 0.5 seconds, then release. Other controls cancel the gesture. Shows/resets A/P/O/N: average/peak CPU load, overruns, governor voice drops. Off by default.
SCRMDATA opens; turn and press DATA; BACK returnsSix checkboxes per track: Pitch, Decay, Color, Shape, Sweep, Contour. Pitch/Decay default Off; Color/Shape/Sweep/Contour default On. Each pattern keeps its own six checklists; Save Project preserves them after reloading. Wizard allows Pitch/Decay; its sample/mode controls stay excluded.
Sidechain routingSelect source; tap SETTINGS + TRACK; S.Chn > DATACheck the five other tracks, Rev. (reverb-slot return), and/or Del. (delay-slot return). DATA toggles each target. Dpt/Atk/Hld/Rel and Mute apply to all selected targets. Choices save per source and pattern with Save Project. Multiple sources use the deepest duck on each target. DUCK is a separate delay type.
Dpt / Atk / Hld / RelScroll below checkboxes; click DATA, turn, click to finishDpt = Depth, Atk = Attack, Hld = Hold, Rel = Release. Depth: 0–100%, 16 levels. Atk: 0–160 ms. Hold: 0–120 ms. Rel: 10 ms–3 s. BACK finishes editing, then returns to Mod Setup. Start with a four-on-the-floor source, Depth 60%, Attack 0 ms, Hold 0 ms, Release 150 ms. Untick all targets to disable that source.
Mute (Sidechain)Select source; S.Chn > Mute; click DATAOn: muting the source stops its sidechain action, including when excluded by solo. Off: muted sources keep ducking their targets (default). Each source saves its choice per pattern with Save Project.
Per-pattern savingSave Project after editsSidechain routing and controls, six Scramble checklists, FX types and added FX settings belong to each pattern. Save the project to keep changes after reloading. Blank patterns have Sidechain off and the default Scramble checklist. Queued changes apply when the next pattern starts.
GrooveGlobal > Grv > On / TypeOff uses stock Swing and remembers Type. On enables Boom Bap, Disco, Reggae, Bongo, Caixixi, Highlife or Kuduro; Swing controls strength. No stock Swing entry in Type.

BACK closes Mod Setup and saves its global preferences. If playback is running, the save waits until it stops. Stop playback and allow saving to finish before powering off. Sidechain routing/settings, Scramble checklists and FX types/added settings are per pattern: Save Project preserves these after reloading. Closing a submenu alone does not save the project.

Fonctions incluses

Machines et son
Six moteurs stock plus Sample Wizard, SD Vintage, Clap Vintage, SY Toy, SY Bits, Swarm LITE, MACRO, ACID, WAVE, Feral de Glycinate, Elder, TINY, Shadow, SPEAK, LEGACY, RETROSYN, PUNCH et MIDI Out. Elder est inspiré de Junior de Fors. PUNCH est un moteur de percussions FM de100demons (MIT).
Performance et séquenceur
Arpège, octave 0 sur notes tenues, ChordKeys et locks d’harmonie, Sequence Genie, SCRAMBLE, slides, préécoute de pas, Step Recorder, mute et solo verrouillés ou quantifiés. Sidechain déclenché par les notes et listes Scramble par pattern.
Filtres et effets
Filtre résonant et attaque par piste. GATED, HALL, ROOM, PS1, Vinyl, Ring Mod et deux Chorus ; DUCK, DUB, Ping Pong, Phaser et deux Crushers.
Routage et travail
MIDI Out avec neuf CC, locks et deux LFO MIDI ; bascule OUT/THRU ; USB stéréo ou six pistes ; sauvegarde permanente, Mod Setup sauvegardé et diagnostic DX facultatif.
