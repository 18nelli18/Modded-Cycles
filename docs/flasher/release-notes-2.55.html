Page Len / Warp

Open Page Setup with FUNC + PAGE. Choose Page Len1–16, then choose Warp OFF or ON. Warp is OFF by default and saves with the pattern. At Page Len4, Warp ON spreads the four steps over the normal16-step duration; OFF repeats the four-step page at its usual step speed. The pattern scale still applies. Hidden steps stay dark in GRID RECORD and cannot be edited until you increase Page Len.Ouvrez Page Setup avec FUNC + PAGE. Choisissez Page Len1–16, puis Warp OFF ou ON. Warp est OFF par defaut et sauvegarde dans le pattern. Avec Page Len4, Warp ON repartit les quatrepas sur la duree normale de16pas ; OFF repete la page de quatrepas a sa vitesse habituelle. L echelle du pattern reste appliquee. Les pas masques restent eteints en GRID RECORD et ne sont pas editables avant d augmenter Page Len.

Warp changes sequencer timing while BPM, MIDI clock and audio sample rate stay native. It does not time-stretch samples or change the meaning of note length and retrig controls.
