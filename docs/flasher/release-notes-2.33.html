2.33 - Ring Mod, Phaser and DUCK2.33 - Ring Mod, Phaser et DUCK

RING MOD joins the reverb FX menu above ROOM: REVERB SEND is Ring Send, SIZE is Frequency, FUNC + SIZE or SETTINGS + SIZE is Depth. Adds metallic sine modulation using a shared stereo return.RING MOD rejoint le menu FX reverb au-dessus de ROOM : REVERB SEND = Ring Send, SIZE = Frequency, FUNC + SIZE ou SETTINGS + SIZE = Depth. Modulation metallique sinusoidale sur retour stereo commun.

PHASER joins the delay FX menu above DUCK: DELAY SEND is Phaser Send, TIME is Rate and FUNC + TIME is Depth. Hold FUNC first, then TRACK + TIME for Feedback, or use SETTINGS + TIME.PHASER rejoint le menu FX delay au-dessus de DUCK : DELAY SEND = Phaser Send, TIME = Rate, FUNC + TIME = Depth. Tenir FUNC puis TRACK + TIME pour Feedback, ou SETTINGS + TIME.

DUCK makes native delay repeats recede while notes play and swell into the gaps. Native Time, Feedback and Send stay accessible. Hold FUNC first, then TRACK: TIME adjusts Amount, DELAY SEND adjusts Release. Try Amount 127 and Release 32-64; Amount 0 restores standard Delay.DUCK attenue les repetitions du delay natif pendant les notes et les fait remonter dans les espaces. Time, Feedback et Send natifs restent accessibles. Tenir FUNC puis TRACK : TIME = Amount, DELAY SEND = Release. Essayer Amount 127, Release 32-64 ; Amount 0 retrouve Delay standard.
