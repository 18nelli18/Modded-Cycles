Supermodel Lite

Each sound machine has its own Punch attack. Full offers 23 sound machines plus MIDI Out; Lite contains the six stock machines.Chaque machine sonore possède sa propre attaque Punch. Full propose 23 machines sonores plus MIDI Out ; Lite contient les six machines d’origine.

The six original Model:Cycles machines, with Supermodel’s shared sequencing, performance, modulation and effects features. Choose Lite in the main flasher. Release 2.63 retains the stock-six startup repair and adds open LOW defaults for new/cleared sounds. Existing saved filter settings remain.Les six machines d’origine du Model:Cycles, avec les fonctions communes de séquence, jeu, modulation et effets de Supermodel. Choisissez Lite dans le flasheur principal. La version 2.63 conserve le correctif de démarrage stock-six et ajoute un filtre LOW ouvert pour les sons neufs/effacés. Les réglages sauvegardés restent conservés.

Lite has no added machines, including Sample Wizard or the MIDI Out machine. Ordinary MIDI functions remain. Sounds using other absent machines stay silent until you choose a stock machine. Notes, locks and shared pattern FX data remain. Lite needs the official Cycles OS file and, for Model:Samples conversion, the Samples OS file. No Syntakt OS file is required. Full adds all the extra machines and their controls.Lite ne contient aucune machine supplémentaire, y compris Sample Wizard et la machine MIDI Out. Les fonctions MIDI ordinaires restent disponibles. Les sons utilisant une autre machine absente restent silencieux jusqu’au choix d’une machine d’origine. Notes, locks et données FX communes restent conservés. Lite demande l’OS Cycles officiel et, pour la conversion Model:Samples, l’OS Samples. Aucun OS Syntakt requis. Full ajoute toutes les machines supplémentaires et leurs commandes.
