Flasher

Supermodel 3.06

What changed in this version…

  • Fixed the blank delay selection window: the seven remaining effect names are visible again in every edition. The removed telephone delay stays removed. Version remains 3.06.
  • Sample Wizard shows Pan while FUNC is held and returns to track level when released. With Num On, both level and pan use numeric values (0–127); Num Off keeps the bars. DATA clicks retain their normal action. This applies to Main and Machine Optional, Full and Lite, with version 3.06 unchanged.
  • The delay menu now contains Phaser, Duck, Dub, Ping Pong, Delay, Crush 1 and Crush 2 in every edition. The telephone delay has been removed; older saved selections use standard Delay. Control All Config remains available. This update stays on 3.06.
  • FX playback-switching fix: changing patterns while playing now restores the saved FX at the live pattern boundary without copying another pattern's settings into the outgoing pattern. This update stays on 3.06. If incorrect choices were already saved, reselect the intended FX and Save Project once.
  • Master FX now stay with each pattern and survive a saved project reload. Effects are shared across all six tracks; the redundant FX/MST menu item has been removed. Save Project before powering off to keep edits.
  • GOV adds INV: when the overload governor must steal a voice, eligible tracks are considered from 6 back to 1. Trk keeps the 1-to-6 order and Lod remains the default. Protection rules, thresholds and fades are unchanged.
  • Track Swap preserves complete track-level values, scrolls through all four Track menu items, and checks project/pattern ownership before changing data. It refuses a swap if the context changes. The reported factory-pattern replacement is not yet reproduced on hardware; these checks guard against mismatched contexts.
  • Main Full, Main Lite and Machine Optional Full/Lite, release notes, guides and printable manuals are updated to 3.06. The preceding test build was confirmed working by the user; all four 3.06 builds are checked in emulation.
