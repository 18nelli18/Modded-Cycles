# Modded Cycles : édition Supermodel d’A.V.

Toutes les données de la banque MIDI restent en RAM et sont perdues à extinction. Save Project sauvegarde uniquement A.

## Audio USB 6 canaux

Six canaux audio USB séparés à 48 kHz / 32 bits, à la place du mixage stéréo USB.

- Sélectionnez les entrées USB 1–6 dans votre DAW. Aucun raccourci supplémentaire.

## Model-TG

Ajoute un Sampler à sept modes, le resampling, beat repeat/effets master, Attack/Filter/Resonance et les slides de paramètres. Inclut mutes verrouillés, préécoute des trigs et noms défilants.

- MACHINES → machine 7 : Sampler. PRESET ci-dessous désigne le bouton MACHINES ; PRESET : charger un sample ; TRIG maintenu + PRESET : verrou de sample.
- SETTINGS + PRESET : modes de lecture ; SETTINGS + PUNCH : options du mode.
- SETTINGS + REC : resampling ; SETTINGS + RETRIG : beat repeat/effets master.
- Page beat repeat : TRIG 1–16 choisit la division ; pads pour les pistes ; potards de paramètres pour les effets.
- SETTINGS + BACK : réinitialiser les effets master ; BACK dans beat repeat réinitialise aussi la répétition.
- PRESET + DECAY / SWEEP / CONTOUR : Attack / Filter / Resonance.
- SETTINGS + TRIG : slide on/off ; FUNC + PAGE : Scale Lock (Scl/Key).
- Maintenez TRACK, appuyez FUNC : verrouiller les mutes ; FUNC quitte. À l’arrêt : TRIG maintenu + PAGE pour préécouter.
- Éditeur de slices : TRIG 1–16 sélectionne/joue ; FUNC accède aux slices 17–32. Potards 1/2 déplacent le marqueur, FUNC + potards 1/2 cale aux passages par zéro, potard 3 zoome.
- Éditeur de slices : DATA divise ; FUNC + DATA supprime un marqueur ; PUNCH démarre/arrête la découpe au tap.
- Device Config → Transfer → SMP : transfert de samples.

## Écoute des samples (Model-TG)

Jouez le sample sélectionné avant de le charger.

- FUNC + MACHINES (PRESET) : ouvrir le navigateur ; sélectionner un sample puis jouer un pad ou une touche TRIG.

## Mode mute verrouillé

Verrouillez les commandes de mute pour les utiliser d’une main.

- Maintenez TRACK, appuyez FUNC : entrer ; pads : mute/unmute ; appuyez FUNC : quitter.

## Écoute d'un pas

Écoutez un pas du séquenceur à l’arrêt ou en pause.

- Maintenez TRIG + PAGE.

## Défilement des noms longs

Lisez les noms longs dans le navigateur de sons.

- Sélectionnez un son avec DATA ; le défilement démarre automatiquement.

## Effacer un trig plus facilement

Un appui bref efface un trig existant ; un appui long le garde pour éditer ses locks.

- Relâchez un TRIG existant en moins de 0,5 s pour l’effacer. Maintenez plus longtemps ou tournez un potard pour éditer.

## Arpégiateur

Ajoute les directions UP, DOWN, UPDN, RAND et PLAY sur 1–4 octaves, à la vitesse du retrigger.

- FUNC + RETRIG : réglages. Maintenez RETRIG et plusieurs notes pour jouer, ou activez A.On.

## Tempo jusqu'à 546 BPM

TEMPO, tap tempo et horloge MIDI reçue acceptent jusqu’à 546 BPM.

- Utilisez les commandes TEMPO normales ; aucun raccourci supplémentaire.

## Démarrage SUPERMODEL

SUPERMODEL apparaît lettre par lettre, avec un trait et la petite signature by A.V. Tout sélectionner privilégie cette animation.

- Lecture automatique à l’allumage. Choisissez SUPERMODEL ou l’animation Modded Cycles.

## Animation de démarrage modded-cycles

Carrés animés et nom Modded Cycles au démarrage.

- Lecture automatique à l’allumage. Choisissez cette animation ou SUPERMODEL.

## Navigateur sur plusieurs lignes

Un navigateur à trois lignes indique sélection, son chargé et dossiers.

- Ouvrez le navigateur PRESET puis tournez DATA.

## Volume et pan en chiffres

Affichez volume 0–127 et panoramique −64 à +63 pendant leur réglage.

- LEVEL/DATA : volume ; FUNC + LEVEL/DATA : panoramique.

## Trigless trigs atténués

Les LEDs des locks trigless sont atténuées ; les trigs de note gardent leur luminosité.

- FUNC + TRIG : créer/effacer un pas de locks trigless.


## Basculer MIDI OUT + THRU en direct

Choisissez si THR émet aussi le MIDI propre au Cycles.

- CONFIG → MIDI → PORTS → OUT/THRU = THR ; FUNC + appui DATA : sortie combinée on/off.
- Un appui DATA seul sélectionne OUT normal.

## Machine MACRO

Ajoute 47 modèles de synthèse, deux contrôles de timbre, une enveloppe et la réduction de fréquence/bits.

- MACHINES : choisir MACRO. SHAPE : modèle ; COLOR/SWEEP : timbre ; CONTOUR : timbre de l’enveloppe.
- FUNC + PITCH : gauche = réduction RATE ; droite = réduction BITS.

## Machine ACID

Ajoute une basse ACID à formes scie/carré, enveloppe de filtre, saturation et legato.

- MACHINES : choisir ACID. COLOR : cutoff ; SHAPE : résonance ; SWEEP : quantité d’enveloppe ; CONTOUR : saturation.
- DECAY : durée ; PUNCH : scie/carré. Faites chevaucher les durées ou les notes tenues pour le legato.

## Chord Keys

Les TRIG jouent les degrés d’accords avec gamme, tonique et extensions au choix ; les pads restent normaux.

- Choisissez CHORD. TRIG 1–7 : degrés I–VII ; 8–14 : octave +1 ; 15–16 : I–II à l’octave +2.
- FUNC + RETRIG : tonique, gamme et triade/7/9/11/13 par degré.

## Filtre par piste (LP / OFF / HP)

Un filtre passe-bas/passe-haut par piste avec résonance et enveloppe, utilisable en locks et LFO.

- Maintenez MACHINES + SWEEP : passe-bas à gauche, off au centre, passe-haut à droite.
- MACHINES + CONTOUR : résonance ; + COLOR : quantité d’enveloppe ; + SHAPE : durée d’enveloppe.

## LFO 2, 3, 4

Les LFO 2–4 ont vitesse, multiplicateur, forme, destination et profondeur indépendants. Fondu, phase et mode suivent LFO 1 ; LFO 2 est sauvé avec le son, LFO 3–4 restent en RAM.

- Appuyez LFO plusieurs fois pour les pages 1–4 ; le cinquième appui ferme. DATA sélectionne/édite les réglages.

## Vrais moteurs du Syntakt

Choisissez les moteurs sonores Syntakt à installer avec les machines Cycles.

- Chargez votre OS Syntakt officiel dans le flasher. Choisissez les moteurs installés avec MACHINES.

## Générateur de séquence

Sequence Genie propose gamme/tonique, plages de notes et vélocité/decay/pan, génération rythme/notes séparée, mutation et rythme euclidien. En lecture, la génération s’applique à la prochaine boucle de la piste choisie.

- SETTINGS + PAGE : ouvrir pour la piste A ou la voie B courante.
- DATA : sélectionner ; appui : éditer ; tourner : changer ; nouvel appui : terminer. Generate applique/met en attente.
- PLAY/STOP : préécouter ; FUNC + pad : mute/unmute du côté courant.
- En attente, sélectionnez Cancel queue pour annuler.
- Arrêtez la lecture pour Undo. Fermer le menu efface Undo et annule la génération en attente.

## Second LFO

Un second LFO avec clavier/potards synthé actifs. Côté A, vitesse, multiplicateur, forme, destination et profondeur sont sauvés avec le son ; fondu, phase et mode reviennent aux défauts au chargement. Les LFO MIDI B restent en RAM.

- Deux appuis LFO : LFO 2. LFO SPEED édite LFO 2 quand sa page est ouverte.
- Côté A seulement : maintenez LFO + tournez un potard de paramètre pour assignation rapide et profondeur signée.
- FUNC + PLAY en enregistrement grille : efface la piste choisie et ses deux LFO. Hors enregistrement grille : efface les séquenceurs du pattern et les deux LFO des six pistes. Répétez pour annuler. Demande Model-TG décoché, ou Model-TG avec ChordKeys.
- Dst côté B : appuyez DATA, parcourez OFF → CC0–127, appuyez DATA pour confirmer ; BACK annule.

## SCRAMBLE

Tire les quatre paramètres de la machine courante, ou les valeurs de base des CC assignés côté B. Des pas A peuvent refaire un tirage à chaque passage. Sampler exclu ; sans Undo.

- SETTINGS + TRACK : SCRAMBLE une fois, avec popup.
- Côté A seulement : maintenez TRIG(s), puis SETTINGS + TRACK, pour activer/désactiver SCRAMBLE sur ces pas.

## Banque MIDI OUT

Six voies MIDI M1–M6 jouent en parallèle des pistes audio : notes éditables, live-rec, locks/slides CC, deux LFO MIDI et Sequence Genie. Canaux 7–12 par défaut, réassignables. Toutes les données B sont perdues à extinction ; Save Project sauve seulement A.

- FUNC + SETTINGS + TRACK : entrer/quitter B depuis son écran principal. BACK ferme une fenêtre ; BACK à l’accueil quitte B.
- Pads : sélectionner/jouer une voie ; FUNC + pad : MIDI on/off. TEMPO ouvre le menu global natif pour les douze pistes ; BACK ou TEMPO ferme et revient à B.
- REC : enregistrement grille/clavier. REC + PLAY : live-rec ; nouvel appui PLAY avec REC maintenu : quantifié/non quantifié.
- TRIG maintenu + tournez DATA : éditer la note. Appuyez DATA pour Note → Vel → Len ; le champ actif est surligné.
- PAGE : prochaine page de 16 pas disponible. FUNC + PAGE : longueur, vitesse, gamme/tonique et canal MIDI ; PAGE dans ce menu change la longueur par 16 pas.
- FUNC + TRACK : réglages KbT/Pad Note ; le clavier reste jouable.
- SETTINGS + potard gris : choisir OFF/CC0–127 ; relâcher SETTINGS confirme. Tourner le potard assigné émet sa valeur de base.
- TRIG maintenu + potard assigné : lock CC. FUNC + TRIG : lock trigless. SETTINGS + TRIG : slide note/CC on/off.
- Les locks CC reviennent à leur base au prochain trig de note actif sans ce lock ; les pas vides/trigless les conservent.
- TRIG maintenu + RETRIG : menu du pas ; nouvel appui RETRIG : on/off. Éditez en maintenant ; relâcher TRIG ferme. FUNC + RETRIG : retrig/arp de voie.
- Potard CHANCE : menu Chance/conditions natif ; maintenez TRIG pour verrouiller, relâchez pour fermer. Assigner ce potard à un CC remplace cette commande.
- FUNC + REC / PLAY / STOP : copier / effacer / coller la voie. Répétez effacer/coller pour annuler.
- TRIG maintenu + REC : copier le pas ; TRIG destination maintenu + STOP : coller, locks compris.
- SETTINGS + PAGE : Sequence Genie. SETTINGS + TRACK : SCRAMBLE des CC assignés.
- LFO : LFO MIDI 1 ; nouvel appui : LFO MIDI 2. Dst → DATA → parcourir → DATA confirme ; BACK annule. Clavier jouable.


ChordKeys nécessite Model-TG. Banque MIDI et machines supplémentaires sont facultatives pour ChordKeys ; sa sélection ne coche plus tous les mods.

Control All Config : TRACK + TRIG1–6 inclut/exclut chaque piste audio, y compris la piste active. TRACK + potentiomètre agit sur les pistes incluses. Choix réinitialisés au redémarrage.
