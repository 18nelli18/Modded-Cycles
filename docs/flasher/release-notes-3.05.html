Supermodel 3.05

What changed in this version…

  • Track Swap: open Mod Setup > Track > Swap while stopped. Select From and To with DATA, then select Swap and press DATA. Sounds, sequences, p-locks, volume, filters, LFO settings and per-track FX move together; sidechain connections and Song mute references follow the swapped contents. Swapping the same pair again reverses the operation. Save Project to keep edits.
  • Available in Full, Lite and Optional. Optional also moves its ChordKeys settings without changing Page Length. Lite keeps its stock-only machine roster. Existing DSP, SRAM audio code and governor thresholds are unchanged from 3.04; no new audio-interrupt work is added.
  • Guides, manuals, startup screens and flashers updated to 3.05. FX clicks and voice stealing remain under investigation.
