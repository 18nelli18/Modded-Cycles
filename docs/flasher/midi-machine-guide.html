MIDI Out machine — controls

Return to flasher / Revenir au flasheur

Controls

This firmware includes the current main features, MIDI Out as an extra machine. The MIDI B-side bank is absent.

  1. Choose MIDI Out from MACHINES on an A-side track. It sends MIDI and produces no internal audio. Existing notes and the normal A-side grid stay on that track. Sequenced MIDI notes do not require the audio track MIDI-output flag. Other tracks can use any audio machine.
  2. Assign a CC: hold SETTINGS and turn a gray knob. Choose OFF or CC0–127. Release SETTINGS; turn the knob alone to send values0–127. The twelve gray knobs correspond to CC01–CC12 on the MIDI panel.
  3. Track Setup: hold FUNC + TRACK. The stock-style menu offers Ch (channel), Out (output), KbT and Pad Note. Glob means Global. Turn DATA to choose a row; press DATA before turning it to edit. Channel offers1–16 or Global; Port offers Global, Off, USB, DIN or Both. BACK returns to the track screen.
  4. CC locks: hold one or more steps and turn an assigned CC knob. Empty steps become lock-only steps. Each lock retains its CC number and value. Live recording also records CC values at the native current step. Use the normal note menus and DATA for note, velocity and length editing.
  5. Two MIDI LFOs: press LFO to cycle LFO1 → LFO2 → track screen. On an LFO page, the first eight gray knobs edit Speed, Mult, Fade, CC destination, Wave, Phase, Mode and Depth. DATA selects a field; click DATA to edit it. Destination offers OFF and CC0–127. BACK returns to the track screen. Audio tracks keep their normal LFO controls.
  6. Pattern length: use FUNC + PAGE and the normal PAGE/DATA controls. MIDI Out uses the same A-side pattern length editor.
  7. External MIDI recording (MIDI-input test v7 firmware): enable note reception in CONFIG > MIDI, then send your keyboard on the track's native receive channel or the auto channel for the selected track. Channel in MIDI Out Track Setup is the output channel; it does not change the receive channel. Incoming notes play through the configured Output and record note, velocity and length in live recording. For Step Recorder, stop playback and double-press REC; play and release each note to advance. CHORD tracks with Keys enabled also show the chord-name banner while a note is held. This input extension is a private test, pending hardware verification.
  8. Save: use normal project saving or FUNC + SETTINGS quick save. MIDI CC assignments, values, both LFO setups and channel/output routing are part of the MIDI sound; note data and locks use the normal pattern.
  9. Return to audio: switching from MIDI Out to an audio machine restores that machine’s default sound parameters. Notes, pattern and pitch stay intact. Held and sequenced notes are released on their original channel and port.

Commandes

Firmware complet avec les fonctions du principal et machine MIDI Out supplementaire. Aucune banque MIDI B.

  1. Choisissez MIDI Out dans MACHINES sur une piste A. Sortie MIDI sans audio interne. Notes et grille A conservees, sans devoir activer le MOut audio pour les notes sequencees ; les autres pistes peuvent utiliser des machines audio.
  2. Assigner un CC : maintenez SETTINGS et tournez un potard gris : OFF ou CC0–127. Relachez SETTINGS ; tournez seul pour envoyer une valeur0–127. Les douze potards correspondent aux CC01–CC12 du panneau MIDI.
  3. Track Setup : maintenez FUNC + TRACK. Menu natif avec Ch (canal), Out (port), KbT et note de pad. Glob signifie Global. DATA choisit une ligne ; cliquez avant de tourner pour modifier. Canal1–16 ou Global ; port Global, Off, USB, DIN ou Both. BACK revient a l'ecran de piste.
  4. Locks CC : maintenez des pas et tournez un CC assigne. Les pas vides deviennent lock-only. Numero CC et valeur sont conserves dans chaque lock. Enregistrement live au pas natif disponible. Menus de notes habituels et DATA pour note, velocite et longueur.
  5. Deux LFO MIDI : LFO parcourt LFO1 → LFO2 → ecran de piste. Huit premiers potards : vitesse, multiplicateur, fade, destination CC, forme, phase, mode, profondeur. DATA choisit un champ ; cliquer pour modifier. Destination OFF ou CC0–127. BACK revient a l'ecran de piste. Controles LFO habituels conserves sur les pistes audio.
  6. Longueur : FUNC + PAGE et commandes PAGE/DATA habituelles. MIDI Out utilise le meme editeur de longueur A.
  7. Enregistrer un clavier MIDI externe (firmware de test MIDI-input v6) : activez la reception des notes dans CONFIG > MIDI. Envoyez les notes sur le canal de reception natif de la piste, ou sur le canal auto pour la piste selectionnee. Channel dans Track Setup MIDI Out est le canal de sortie, sans changer celui de reception. Les notes entrantes utilisent le port Output choisi ; notes, velocite et duree s'enregistrent en live. Pour Step Recorder, arretez la lecture et appuyez deux fois sur REC ; jouez et relachez chaque note pour avancer. Les pistes CHORD avec Keys montrent aussi le nom de l'accord tenu en MIDI. Extension en test prive, validation materielle encore necessaire.
  8. Sauvegarder : sauvegarde projet habituelle ou FUNC + SETTINGS. Assignations/valeurs CC, deux configurations LFO et routage sont dans le son MIDI ; notes et locks restent dans le pattern.
  9. Retour audio : quitter MIDI Out pour une machine audio retablit les parametres sonores par defaut de cette machine. Notes, pattern et Pitch restent intacts. Les notes tenues/sequencees sont fermees sur leur canal/port initial.
