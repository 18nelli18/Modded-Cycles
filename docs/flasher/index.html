Flasher Web MIDI — Model:Cycles

Envoie un firmware .syx a l'Elektron Model:Cycles (ou Model:Samples) depuis Chrome / Edge / Opera, par Web MIDI. C'est le pendant navigateur de tools/flash.py.

A lire avant. Flasher un firmware modifie met la garantie en jeu et se fait a tes risques.
  • Tout se passe dans ton navigateur : le .syx n'est envoye a aucun serveur. Aucune image firmware n'est fournie ici — tu apportes la tienne.
  • STARTUP MENU (OS UPGRADE) n'ecoute que le MIDI IN (jack TRS) de l'appareil : envoie vers ton interface MIDI (dont la sortie va au MIDI IN). Le port USB de l'appareil ne marche pas dans ce menu.
  • CONFIG > UPGRADE (OS en marche) recoit par USB : la, tu peux viser le port « Model:Cycles » directement. Ne marche que si l'USB de l'appareil transporte l'OS (stock, ou variante 6ch-usbup).
  • Garde une interface MIDI et l'OS officiel a portee : c'est ton seul secours si l'appareil ne redemarre plus. Voir FLASH.md et note 13.

1Autoriser le MIDI

Clique « Activer le MIDI », puis accepte la demande d'autorisation (avec SysEx).

2Le fichier .syx a envoyer

Deux options : construire l'image modifiee ici a partir de ton OS officiel, ou deposer un .syx deja pret (mod, ou OS officiel pour revenir en arriere).

Construire le .syx dans le navigateur

Depose ton OS officiel model-cycles_OS1.13.syx (dezippe depuis elektron.se). Rien n'est envoye a un serveur ; l'image se fabrique dans la page.

Glisse l'OS officiel .syx ici, ou clique.

3Choisir le port et flasher

Mets d'abord l'appareil en reception : eteindre → maintenir FUNC → allumer → TRIG 4 (OS UPGRADE). L'ecran affiche READY TO RECEIVE. (Ou, pour l'USB direct : CONFIG > UPGRADE depuis l'OS en marche.)
