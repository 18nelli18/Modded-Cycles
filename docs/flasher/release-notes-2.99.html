Global DX On enables the live CPU monitor: hold SETTINGS and press BACK. PAGE switches load/track-cut pages; DATA press clears counters. Quick double-BACK exits. Knob turns, transport and trigs continue normally while parameter popups stay behind the monitor. The old FUNC popup is removed.

Global DX On active le moniteur CPU : SETTINGS + BACK. PAGE change de page ; clic DATA remet les compteurs a zero ; double BACK rapide quitte. Potards, transport et trigs restent disponibles sans masquer le moniteur. Ancien popup FUNC retire.

Single BACK retains native parameter undo in CTRL-ALL latch; quick double-BACK exits the latch outside the monitor. Machine browsing defaults to Stk and preserves a saved Sil preference. Stock-machine PUNCH remains native.

BACK simple conserve l annulation native avec le verrou CTRL-ALL ; double BACK rapide quitte le verrou hors moniteur. Parcours machines Stk par defaut, preference Sil sauvegardee conservee. PUNCH des machines stock reste natif.

Shared controls are included in Full, Lite and Machine Optional. Optional retains its extra machine choices. Updated SysEx sequence/checksum handling supports the Cycles and Samples delivery paths. Validation is software/emulation, not exhaustive hardware coverage.

Commandes partagees dans Full, Lite et Machine Optional, qui garde ses machines supplementaires. Transport SysEx corrige pour les chemins Cycles et Samples. Validation logicielle/emulation ; pas de couverture materielle exhaustive.

Known issue: long notes can still be cut on some stock patterns. Voice stealing is unresolved; this release does not claim to fix it.

Probleme connu : certaines longues notes restent coupees sur des patterns stock. Le vol de voix reste non resolu ; cette version ne pretend pas le corriger.

Optional keeps its extra machine choices. Hardware coverage varies by combination.
