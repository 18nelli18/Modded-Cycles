# Supermodel 909 — A.V.’s Edition

Separate browser builder: four local WAV inputs plus the official Cycles OS 1.13. Audio never leaves the browser. Six stock engines are replaced by Model909; ACID, SCRAMBLE, MIDI Bank, Out/Thru, Sequence Genie, latching mute, Second LFO and Control All Config are included. MIDI Bank remains RAM-only. Same MIDI classic/fast transports as main.

Released edition, hardware tested by A.V. on 14 October 2026, including the local sample uploader, combined features and 909 startup animation. Model909 by DMDaudio (MIT); see LICENSE-Model909.txt. Main flasher unchanged.
