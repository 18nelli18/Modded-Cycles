# 2026-10-13-midi-cc-stock-retrig

Hold a TRIG and turn an assigned gray knob to lock its CC value on that step. A LOCK badge appears. Step playback sends the saved CC number/value; an unlocked note restores the assigned base value. Step/lane copy, paste and clear include these locks. CC assignments and CC locks are RAM-only and reset on project load/restart; Save Project does not save CC locks in this first test. MIDI notes, timing, older step locks and MIDI LFO saving are unchanged. Experimental gray-knob CC controls in MIDI B-side. Hold SETTINGS and turn a gray knob to select OFF or CC0-127. Common CC names appear in the stock-style window and long names scroll. Release SETTINGS, then turn the knob to send a value on the selected MIDI lane channel and port. Assignment itself sends nothing. Muted/disabled lanes send nothing; unassigned knobs retain their earlier behavior. A-side controls are unchanged. The first test keeps assignments in RAM only, so they reset after restart. Hardware-tested MIDI sequence saving and live recording remain included.
