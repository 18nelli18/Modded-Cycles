# Independent MIDI Bank test

Experimental selectable backends. MIDI Bank no longer forces Model-TG, Sequence Genie, Second LFO, SCRAMBLE, Live MIDI OUT+THRU or extra machines. MIDI data is RAM-only. Physical MIDI/USB timing requires hardware verification. Main unchanged.
