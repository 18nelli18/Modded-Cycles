# Independent MIDI OUT Bank — experimental

Select **MIDI OUT Bank** alone or alongside your chosen main-flasher features. The complete machine set includes RETROSYN, TINY and WAVE; Sample Wizard stays optional. Choose either startup animation and the retained Second LFO. MODEL TG remains blocked.

Open B with **FUNC + SETTINGS + TRACK**. Six MIDI lanes default to channels 7–12. CC assignments, locks, slides, live recording, retrigger, chance and two MIDI CC LFOs remain available. Genie and SCRAMBLE act on B when selected. TEMPO opens the native global menu.

**B-side is RAM only. Power-off loses B data. Save Project saves A only.** This independent integration is experimental; emulator results do not establish hardware reliability or physical MIDI timing. The main flasher is unchanged. See [technical proof](../../notes/97-banque-midi-actuelle.md).
