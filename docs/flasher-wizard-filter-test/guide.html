Getting started

Adds Wizard as machine 7, keeping the six stock machines. Includes the sampler playback modes, sample browser, Slice editor and Slice varispeed. This integration profile includes the compatible Supermodel features, all 15 machines and ChordKeys, without requiring Model-TG. Main and the previous test pages are unchanged. No samples or firmware are supplied.

  1. Choose MACHINES → Wizard (machine 7).
  2. Device Config → Transfer → SMP: use Elektron Transfer to upload your own samples. Return Transfer to CYC before upgrading firmware.
  3. FUNC + MACHINES: open the browser and choose a sample.
  4. SETTINGS + MACHINES: choose the playback mode. SETTINGS + PUNCH: options for the selected mode.
  5. Slice mode: notes choose the slice; PITCH changes speed/pitch without moving that slice.
  6. Slice editor: TRIG 1–16 selects/plays slices; FUNC accesses slices 17–32. Knobs 1/2 move markers; FUNC + those knobs snaps to zero crossings; knob 3 zooms.
  7. Slice editor: DATA divides; FUNC + DATA deletes a marker; PUNCH toggles tap chopping.

Hardware check: use a fresh project, select Wizard on one track, upload a short sample and check notes, Slice/PITCH, then switch that track back to a stock machine. This release has passed emulation checks; hardware verification is pending.

Premiers pas

Ajoute Wizard comme machine 7 en conservant les six machines stock. Modes sampler, navigateur de samples, éditeur de slices et Slice varispeed inclus. Ce profil intègre les fonctions Supermodel compatibles, les 15 machines et ChordKeys, sans imposer Model-TG. Main et les tests précédents restent inchangés. Aucun sample ni firmware fourni.

  1. MACHINES → Wizard (machine 7).
  2. Device Config → Transfer → SMP : envoyer vos samples avec Elektron Transfer. Revenir à CYC avant une mise à jour du firmware.
  3. FUNC + MACHINES : ouvrir le navigateur et choisir un sample.
  4. SETTINGS + MACHINES : mode de lecture. SETTINGS + PUNCH : options du mode.
  5. Mode Slice : les notes choisissent la tranche ; PITCH change vitesse/hauteur sans déplacer cette tranche.
  6. Éditeur : TRIG 1–16 sélectionne/joue ; FUNC accède aux tranches 17–32. Potards 1/2 : marqueurs ; FUNC + ces potards : passages par zéro ; potard 3 : zoom.
  7. Éditeur : DATA divise ; FUNC + DATA efface un marqueur ; PUNCH active/désactive le découpage au tap.

Premier test matériel : projet neuf, Wizard sur une piste, sample court, notes puis Slice/PITCH ; revenir ensuite à une machine stock. Preuves émulation réussies ; validation matérielle en attente.

Shared per-track filter

Hold MACHINES and turn SWEEP for low-pass cutoff or CONTOUR for resonance. Select All includes this shared version with Sample Wizard and Second LFO. Wizard keeps its own filter; synth/drum tracks receive the same ladder algorithm. Cutoff 127 and resonance 0 bypass processing. Hold a TRIG to lock a value; CC74 controls cutoff and CC71 resonance. Settings save with the sound. This is a low-pass filter, without the previous high-pass or filter-envelope controls. Experimental, pending hardware verification.

Filtre partagé

MACHINES + SWEEP : coupure passe-bas ; MACHINES + CONTOUR : résonance. Compatible Wizard et Second LFO dans Tout sélectionner. Wizard conserve son propre filtre. Coupure 127 et résonance 0 : bypass. Tenir un TRIG pour un lock ; CC74 coupure, CC71 résonance. Réglages sauvegardés avec le son. Pas de passe-haut ni enveloppe séparée. Test matériel en attente.

TINY

TINY adds 52 percussion models by @Glycinate. SHAPE selects the model. Its combined Sample Wizard variants are included when TINY is selected alone, with WAVE, or in Select All. The shared per-track filter remains available in the Wizard-backed test build. Other partial engine combinations are not covered by this test.
