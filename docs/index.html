Modded-Cycles

Mod USB multipiste (6 canaux) pour l'Elektron Model:Cycles.

Flasher en ligne

Envoie un firmware .syx a ton Model:Cycles depuis Chrome, par Web MIDI. Aucune image firmware n'est fournie ni transmise a un serveur : tu apportes ton propre fichier.

Ouvrir le flasher

Depot, code et documentation : github.com/18nelli18/Modded-Cycles. Projet non affilie a Elektron.
