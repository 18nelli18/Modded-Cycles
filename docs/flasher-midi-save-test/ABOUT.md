# 2026-10-13-midi-save-startup-restore

Experimental MIDI pattern saving and startup restoration. Save Project writes and verifies the B-side sequences. On startup or loading a different saved project, its MIDI sequences are restored in the background. Wait for restoration before editing or saving. Unsaved edits are not autosaved. The native write check was verified on hardware; power-cycle restoration still needs testing. Uses separate MIDI files outside normal Elektron project backups. All existing mod selections, Model-TG, and the tested LFO2 speed knob remain available. Grid recording only in this storage diagnostic.
