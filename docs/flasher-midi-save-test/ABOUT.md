# 2026-10-13-midi-save-native-io-owner

Experimental MIDI write/recovery test. Native file call arguments are corrected. Save As retains the MIDI bank only when the project, bank table and load generation match the captured Save entry. Writes use chunks of at most 512 bytes and resume positive partial writes; zero/error aborts without a success message. A same-project native reload retains the edited MIDI bank and its access after a failed save. A successful native Save Project can now initialize the MIDI save context directly from the confirmed active project and saved slot when the Load notification was missed, preserving edited B-side notes. Startup and loading a different project deliberately start the MIDI bank empty; this build does not restore MIDI sequences. Use a fresh saved project for this test. Edit a B-side pattern and use Save Project: MIDI SAVED requires a complete write, finalization, close and byte-for-byte read-back verification. A-side native sound/project saving stays active. Existing mod selections and the hardware-tested five-setting audio LFO save remain available. MIDI persistence across restart is not claimed. Failure diagnostics identify the save stage. This is separate from main and the trig-clear test.
