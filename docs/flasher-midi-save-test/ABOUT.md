# 2026-10-12-midi-save-first-write

Experimental Save Project write test. Startup and project loading deliberately start the MIDI bank empty; this build does not restore MIDI sequences. Use a fresh saved project for this test. Edit a B-side pattern and use Save Project: MIDI SAVED requires a complete write, finalization, close and byte-for-byte read-back verification. A-side native sound/project saving stays active. Existing mod selections and the hardware-tested five-setting audio LFO save remain available. MIDI persistence across restart is not claimed. Failure diagnostics identify the save stage. This is separate from main and the trig-clear test.

Test expérimental écriture Save Project. Démarrage et chargement de projet ouvrent une banque MIDI vide ; aucune restauration MIDI dans ce build. Utilisez un projet neuf déjà sauvegardé. Éditez un pattern B puis Save Project : MIDI SAVED exige écriture, finalisation, fermeture et relecture identique. Sauvegarde native A active. Mods existants et sauvegarde des cinq réglages LFO audio testée sur matériel conservés. Aucune persistance MIDI après redémarrage revendiquée. Diagnostic précis de l’étape d’échec. Test séparé de main et du test effacement trig.
