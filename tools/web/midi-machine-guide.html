Controls

This fixed test preset includes the current main features, CPU/CUT diagnostics and MIDI Out as an extra machine. The MIDI B-side bank is absent. Hardware verification is pending.

  1. Choose MIDI Out from MACHINES on an A-side track. It sends MIDI and produces no internal audio. Existing notes and the normal A-side grid stay on that track. Other tracks can use any audio machine.
  2. Assign a CC: hold SETTINGS and turn a gray knob. Choose OFF or CC0–127. Release SETTINGS; turn the knob alone to send values0–127. The twelve gray knobs correspond to CC01–CC12 on the MIDI panel.
  3. Channel and output: tap SETTINGS. Turn DATA to choose a row; press DATA before turning it to edit. The first two gray knobs also edit Channel and Port directly. Channel offers1–16 or Global; Port offers Global, Off, USB, DIN or Both. BACK returns to the track screen.
  4. CC locks: hold one or more steps and turn an assigned CC knob. Empty steps become lock-only steps. Each lock retains its CC number and value. Live recording also records CC values at the native current step. Use the normal note menus and DATA for note, velocity and length editing.
  5. Two MIDI LFOs: press LFO to cycle LFO1 → LFO2 → track screen. On an LFO page, the first eight gray knobs edit Speed, Mult, Fade, CC destination, Wave, Phase, Mode and Depth. DATA selects a field; click DATA to edit it. Destination offers OFF and CC0–127. BACK returns to the track screen. Audio tracks keep their normal LFO controls.
  6. Pattern length: use FUNC + PAGE and the normal PAGE/DATA controls. MIDI Out uses the same A-side pattern length editor.
  7. Save: use normal project saving or FUNC + SETTINGS quick save. MIDI CC assignments, values, both LFO setups and channel/output routing are part of the MIDI sound; note data and locks use the normal pattern.
  8. Load diagnostic: hold TRACK + RETRIG, then release either button to see CPU average/peak and CUT. Beat repeat remains audio-only. Test MIDI notes, CC locks, save/reload, both ports and mixed audio/MIDI playback.

Commandes

Preset fixe avec les fonctions actuelles du principal, diagnostic CPU/CUT et machine MIDI Out supplementaire. Aucune banque MIDI B. Verification materielle attendue.

  1. Choisissez MIDI Out dans MACHINES sur une piste A. Sortie MIDI sans audio interne. Notes et grille A conservees ; les autres pistes peuvent utiliser des machines audio.
  2. Assigner un CC : maintenez SETTINGS et tournez un potard gris : OFF ou CC0–127. Relachez SETTINGS ; tournez seul pour envoyer une valeur0–127. Les douze potards correspondent aux CC01–CC12 du panneau MIDI.
  3. Canal et port : appuyez sur SETTINGS. DATA choisit une ligne ; cliquez avant de tourner pour modifier. Les deux premiers potards gris modifient directement canal et port. Canal1–16 ou Global ; port Global, Off, USB, DIN ou Both. BACK revient a l'ecran de piste.
  4. Locks CC : maintenez des pas et tournez un CC assigne. Les pas vides deviennent lock-only. Numero CC et valeur sont conserves dans chaque lock. Enregistrement live au pas natif disponible. Menus de notes habituels et DATA pour note, velocite et longueur.
  5. Deux LFO MIDI : LFO parcourt LFO1 → LFO2 → ecran de piste. Huit premiers potards : vitesse, multiplicateur, fade, destination CC, forme, phase, mode, profondeur. DATA choisit un champ ; cliquer pour modifier. Destination OFF ou CC0–127. BACK revient a l'ecran de piste. Controles LFO habituels conserves sur les pistes audio.
  6. Longueur : FUNC + PAGE et commandes PAGE/DATA habituelles. MIDI Out utilise le meme editeur de longueur A.
  7. Sauvegarder : sauvegarde projet habituelle ou FUNC + SETTINGS. Assignations/valeurs CC, deux configurations LFO et routage sont dans le son MIDI ; notes et locks restent dans le pattern.
  8. Diagnostic : tenir TRACK + RETRIG puis relacher un bouton affiche CPU moyenne/pic et CUT. Beat repeat audio seulement. Verifiez notes MIDI, locks CC, sauvegarde/rechargement, ports et lecture audio/MIDI mixte.
